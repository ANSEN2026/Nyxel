# Nyxel v0.2 Alpha（贴图颜色 / 截图 / 文件管理 / 视频压缩增量）

贴图、FBX 模型与配色分析桌面应用。当前是在 v0.1 MVP 基础上，按 `Nyxel-需求规格-v0.2.md` 做的 v0.2 增量版本。

- B站：https://space.bilibili.com/354642845?spm_id_from=333.1007.0.0
- 爱发电：https://ifdian.net/a/nyxelstudio
- QQ 群：757979659

## 最新增量

- **贴图预览颜色校正**：贴图查看器不再对 sRGB 贴图做二次解码，预览颜色与原图保持一致
- **黑白与色阶**：贴图工具栏新增「黑白」开关；开启后可调黑场、白场、伽马，实时预览并应用到 PNG 导出
- **截图预览与标记**：框选后先进入预览窗口，支持画笔、荧光笔、矩形、箭头、撤销 / 重做、清空；点「批准并保存」后弹出保存位置，也可直接复制到剪贴板
- **文件管理**：左侧栏新增「图库」和「贴图资源」；图库自动记录每次截图，贴图资源支持新建文件夹、导入贴图，点卡片可直接在贴图工作区打开
- **关于我们**：左侧栏底部新增圆形感叹号按钮，展示 B站、爱发电、GitHub 和 QQ 群信息，链接可直接打开
- **检查更新**：设置 → 关于 → 检查更新，通过 GitHub Releases 按稳定 / 测试通道查询；发现新版本可直接打开下载页
- **视频压缩**：左侧栏新增视频工作区，支持 H.264 / H.265、CRF、分辨率、帧率和音频设置；首次使用按需下载 ffmpeg，压缩过程显示进度、可取消
- **导航图标**：贴图改为网格图标，模型改为三维立方体图标
- **配色分析工作区**（Ctrl+3）：4 / 6 / 8 / 12 色提取，感知 / 像素占比，忽略近黑近白，透明像素阈值
- 横向堆叠色条 + 色块列表（HEX / 占比 / 中文近色名），占比 < 1% 归入「其他」
- 悬停色块高亮图片中对应像素，点击复制 HEX，支持导出 JSON
- **贴图 ↔ 配色共享同一张 ImageBitmap**：贴图区点「配色分析」或配色区点「从贴图区获取」
- 设置新增「配色」分类；`settings.json` 升级到 `schemaVersion: 2`，兼容旧配置
- 左侧导航新增配色图标与 `Ctrl+3`
- 左侧导航新增「图库 / 贴图资源」与 `Ctrl+4` / `Ctrl+5`
- 左侧导航新增「视频压缩」与 `Ctrl+6`
- **截图改为可拖拽框选区域**：多显示器各自覆盖，双击 / Enter 进入预览，Esc 取消
- 设置新增「截图保存位置」，可单独更改截图目录
- **模型工作区新增 UV 检视**（3D / UV 切换）：UV 标尺与 U/V 轴标记、多 UV 通道、材质分组、棋盘 / 纯色 / 当前贴图背景、2×2 象限平铺对比、越界标红、重叠检测、Texel Density、3D ↔ UV 双向选中
- **通道打包**：R / G / B / A 四路可分别选择当前图通道、常量，或载入独立贴图；实时预览，支持导出 PNG 或应用回当前贴图
- **法线贴图识别**：自动识别法线贴图，支持 G 通道 OpenGL / DirectX 方向反转，水平翻转时给出提示
- **AI 超分**：Upscayl / Real-ESRGAN 双引擎，2× / 3× / 4×；Upscayl 可选 Standard / Ultrasharp / Ultramix Balanced / Remacri 模型，模型按需下载（每个约 33 MB）；另有本地 2× / 3× 快速放大和「导出 PNG」
- **超分对比**：生成结果后进入原图 / 超分对比视图，中间分割线可左右拖动，确认后应用或取消
- **品牌图标换成机器人吉祥物**：安装包 / 任务栏 / 侧边栏 / 首页统一使用，小尺寸使用头部特写版本
- **顶部标题栏改为简约绿色**，侧边栏选中图标、主按钮和强调色同步改为鹅卵绿

## v0.1 已实现

- **外壳**：无边框窗口、自定义标题栏、左侧栏（首页 / 贴图 / 模型 / 配色）、状态栏、单实例
- **首页**：打开贴图 / 打开模型、拖拽区、最近项目（最多 8 项）
- **贴图工作区**
  - 文件对话框、拖拽、`Ctrl+V` 粘贴导入
  - PNG / JPG / WebP / BMP / GIF / TGA
  - 旋转 ±90°、水平翻转、垂直翻转
  - RGBA / R / G / B / A 通道视图
  - 像素探针（RGBA 0–255、0–1、HEX）
  - 滚轮缩放、拖拽平移、适配窗口、按住空格看 1:1 原图
  - 撤销 / 重做（20 步）
  - 背景：纯黑 / 中灰 / 棋盘格
- **模型工作区**
  - FBX 导入，弹窗选择 Y-up / Z-up（默认 Y-up）
  - 轨道相机：旋转、平移、滚轮缩放、Fit View
  - 三角面数、包围盒尺寸（cm）
  - 1×1×1 cm 参考方块
  - 光照开关、方向光角度
  - 外部贴图 + Clamp / Wrap（仅预览，不改原材质）
  - FBX 版本过低检查、解析失败提示、贴图缺失警告
- **设置**：规格中的 10 项（主题、语言、导出目录、恢复工作区、硬件加速、缓存、ffmpeg 占位、截图热键、更新通道、关于）
- **截图**：全局热键 `Ctrl+Alt+A`、**可拖拽框选区域**（多显示器各自覆盖）、框选后进入预览/标记窗口、批准后选择保存位置、复制到剪贴板
- **打包**：NSIS 安装包、应用图标

## 运行

```bash
npm install
npm run dev     # Vite + Electron 开发模式
npm run build   # 构建 renderer + electron
npm run start   # 构建后启动
npm run dist    # 生成 NSIS 安装包
```

也可以双击 **`启动 Nyxel.cmd`**（会优先启动 `release/win-unpacked/Nyxel.exe`）。

> 在 Cherry Studio Agent 的终端里启动时，环境可能带有 `ELECTRON_RUN_AS_NODE=1`，会让 Electron 变成 Node。`启动 Nyxel.cmd` 和 npm 脚本已经会清空该变量。

## 已知限制（相对完整规格）

- 本次做了 **v0.2 的配色分析、UV 检视、通道打包/法线识别、AI 超分增量**；素材库、`.nyx` 项目文件、只读分享包、媒体处理仍未实现
- 截图标记支持画笔、荧光笔、矩形和箭头；文字标注、马赛克和二次裁剪暂未加入
- 截图窗口吸附、选区尺寸微调尚未实现
- 图库与贴图资源默认保存在 `文档\Nyxel\Library`；删除会移到系统回收站，暂不支持拖拽导入和文件夹重命名
- UV 检视目前以「面」为单位选取，重叠检测为 512 网格近似；UV 岛级选中、精确重叠面积与 Texel Density 后续再补
- 通道打包按当前贴图尺寸输出，超过 4096 会按比例缩小；打包源暂支持常见 PNG/JPG/WebP/BMP/TGA
- AI 运行时首次使用需联网下载，之后离线可用；Upscayl / Real-ESRGAN 都需要可用的 Vulkan 设备
- Upscayl 模型按选择单独下载（每个约 33 MB），首次切换模型需要联网；下载失败会自动尝试备用镜像
- Upscayl 运行时与模型从上游按需下载，未随安装包分发；Upscayl 为 AGPLv3，正式发布前需复核许可与模型授权
- EXR / HDR 贴图预览未接；TGA 已支持
- 语言切换只保存配置，尚未接入完整 i18n
- 硬件加速设置只保存，未在启动前实际应用
- 自动更新目前是「检查并跳转 GitHub Release」，自动下载安装和 `latest.yml` 热更新尚未接入
- 视频压缩首次使用需下载约 200 MB 的 ffmpeg 运行时（BtbN GPL 构建）；当前提供单文件压缩，批量队列和硬件编码预设尚未接入
- 使用 ffmpeg 时请遵循对应上游项目的 GPL 许可；正式公开分发前建议复核许可与再分发方式
- 最近项目暂无缩略图
- FBX UpAxis 默认 Y-up，弹窗可选 Z-up；尚未读取文件 GlobalSettings
- Windows 10 上 DWM 圆角降级为普通窗口；Windows 11 可继续接圆角 / Mica
- 安装包未签名，Windows SmartScreen 会提示
